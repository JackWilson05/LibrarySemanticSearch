# LibrarySemanticSearch

Using HNSW RAG to search library catalogue. Open source implementation with helper files to create database and starter code for web interface. Currently finetuning the model for more effective retrieval with plans to develop an api and local hosting options for lower power machines.

Example data created from https://cseweb.ucsd.edu/~jmcauley/datasets/goodreads.html#:~:text=These%20datasets%20were%20collected%20in,or%20use%20for%20commercial%20purposes

Possible smaller datasources/evaluation sources:
https://www.kaggle.com/datasets/elvinrustam/books-dataset
https://www.kaggle.com/datasets/bahramjannesarr/goodreads-book-datasets-10m.
